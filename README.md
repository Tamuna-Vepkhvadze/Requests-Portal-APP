# QA აუდიტის პლათფორმა

**ავტორი:** თამუნა ვეფხვაძე

ერთი ფაილიანი (single-file) React აპლიკაცია საქმეების (cases) და შემთხვევების (incidents) აუდიტორული ჟურნალის საწარმოებლად. მუშაობს პირდაპირ ბრაუზერში, მონაცემები ინახება **ლოკალურად**, დაშიფრული სახით, `IndexedDB`-ში გარე სერვერი ან backend არ არსებობს.

---

## ✨ ძირითადი ფუნქციები

- **საქმეების/შემთხვევების ჟურნალი** დამატება, რედაქტირება, წაშლა, ძებნა, მრავალპარამეტრიანი ფილტრაცია (თარიღი/კვირა/თვე/კვარტალი/წელი, სტატუსი, კატეგორია, ადრესატი და ა.შ.)
- **მიმოხილვის დეშბორდი** KPI ბარათები, დონატ/ბარ დიაგრამები არჩეული პერიოდისთვის
- **თანამშრომლების მართვა** ცალკეული თანამშრომლის სტატისტიკა და PDF ანგარიში
- **Excel ექსპორტი** (ExcelJS) დაფორმატებული ჟურნალი + ვიზუალური დეშბორდი ჩაშენებული დიაგრამებით
- **PDF გენერაცია** ბრაუზერის print-ის საშუალებით (ცალკეული ჩანაწერის ან თანამშრომლის/კატეგორიის ანგარიში)
- **მორგებადი (Custom) ველები** text / textarea / dropdown ტიპის დამატებითი ველების შექმნა Settings-იდან, ცალკ-ცალკე ან საერთოდ Cases/Incidents-ისთვის
- **დუბლიკატების შემოწმება** რეალურ დროში (Jira №, პირადი №, საქმის №)
- **დაშიფრული Backup / Restore** — JSON ფაილად ექსპორტი, პაროლით დაცული, დაშიფრული

## 🔐 უსაფრთხოება

| კომპონენტი | გამოყენებული ალგორითმი |
|---|---|
| გასაღების წარმოშობა | PBKDF2-SHA256, 310,000 იტერაცია |
| ვერიფიკაცია vs დაშიფვრის გასაღები | HKDF-SHA256 (domain-separated, v2 schema) |
| მონაცემთა დაშიფვრა | AES-256-GCM |
| შენახვა | IndexedDB (`qa_audit_secure_v1`) |
| Login lockout | 5 არასწორი მცდელობა → 5 წუთიანი დაბლოკვა |

**⚠️ მნიშვნელოვანი შეზღუდვები, რაც უნდა იცოდე:**
- ეს არის **client-side only** უსაფრთხოება მონაცემები არასდროს ტოვებს ბრაუზერს, მაგრამ ეს ასევე ნიშნავს, რომ **პაროლის დაკარგვა = მონაცემების შეუქცევადი დაკარგვა.**
- Login lockout ინახება `localStorage`-ში ტექნიკურად შემოვლადია (localStorage-ის გასუფთავებით), ეს არ არის სერვერული rate-limiting-ის ეკვივალენტი.
- აპლიკაცია სრულად **დამოკიდებულია ინტერნეტზე** გაშვების მომენტში (იხ. „ცნობილი შეზღუდვები" ქვემოთ).
**მონაცემები მხოლოდ ლოკალურია**  სხვა მოწყობილობაზე/ბრაუზერში წვდომისთვის საჭიროა ხელით Backup/Restore.

## 🖥 გაშვება

1. გახსენი `app.html` ბრაუზერში (Chrome/Edge/Firefox, უახლესი ვერსია რეკომენდებულია საჭიროა Web Crypto API და IndexedDB მხარდაჭერა).
2. პირველი გაშვებისას მოხდება რეგისტრაცია (ელფოსტა + პაროლი, მინ. 8 სიმბოლო).
3. **საჭიროა აქტიური ინტერნეტ კავშირი** React, ReactDOM და ExcelJS იტვირთება CDN-იდან (cdnjs.cloudflare.com), ასევე ფონტები Google Fonts-იდან.

## 🛠 Backup / Restore

- **დაშიფრული Backup** ცალკე პაროლით დაცული `.json` ფაილი
